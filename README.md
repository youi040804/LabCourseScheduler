# 地大机房排课助手

> 基于 C++/Qt6 的机房排课管理系统 —— 轻松管理教学楼机房课程安排

## 项目简介

**地大机房排课助手** 是一个面向高校机房管理的排课系统，基于 **C++/Qt6** 开发。系统提供直观的图形界面，支持机房浏览、课程排课、报表生成与使用统计等核心功能，帮助管理人员高效地完成机房课程安排工作。

## 核心功能

| 功能模块     | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **浏览功能** | 按教学楼/机房查看排课表，直观展示各时段课程安排              |
| **排课功能** | 支持按课程、教师、班级等信息进行排课，左键双击添加、右键单击取消 |
| **报表生成** | 根据课程、教师、班级生成格式化的排课报表（HTML 表格）        |
| **使用统计** | 按学院→教师→班级→课程维度统计机房使用情况                    |

## 操作说明

### 浏览功能

- 选择教学楼和机房，表格自动显示该机房的排课情况
- 点击已排课单元格，状态栏显示课程详情

### 排课功能

1. 填写排课信息（课程、教师、教师学院、班级、学生学院、排课次数）
2. 点击“开始排课”，在排课表中进行操作：
   - **左键双击**空白单元格 → 添加排课
   - **右键单击**已排课单元格 → 取消排课（仅限当前课程）
3. 排课完成后切换标签页即可结束

### 报表功能

- 选择课程、教师、班级，点击“生成报表”查看排课明细
- 报表以 HTML 表格形式展示，支持复制或打印

### 统计功能

- 点击“生成统计表”，查看机房使用情况汇总
- 按学院→教师→班级→课程层级展示使用次数


## 数据持久化

系统使用 `schedules.json` 文件保存排课记录，首次运行时自动创建。包含：

- 排课记录列表
- 排课编码计数器
- 课程-教师-班级与排课码的映射关系

## 限制说明

- 排课表固定为 5 周 × 3 个时段（上午/下午/晚上）
- 起始周为每年 2 月 17 日（周一）
- 同一时段同一机房只能安排一门课程
- 仅支持取消当前排课课程，不可取消其他课程
